# SPI NAND：主数据、OOB 与片内 ECC

转储布局和片内 ECC 分开选择，沿用 IMSProg 的读取、校验、写入、擦除及自动流程。

## 两个独立选项

- 布局：仅主数据，或主数据 + OOB（每页主数据后紧跟该页 OOB）。
- 片内 ECC：开（纠错读取），或关（原始读取）。

切换布局时 ECC 会自动设为常用值：主数据 + OOB → 关，仅主数据 → 开，之后仍可手动修改。只改 ECC 不访问芯片，也不清空缓冲区；改布局会清空缓冲区，有数据时先确认。每次操作前程序读取芯片 ID，设置 B0 寄存器的 ECC-E 位并回读确认；Winbond 芯片同时设置 BUF=1。

## ECC 开启时遇到无法纠正的页

读取、校验和查空**不会因此中断**：该页按原样（未纠正）读出，操作完成后弹窗汇总无法纠正的页数和涉及的块，纠正过的页数显示在信息栏。

- 少量页无法纠正：通常是坏块或磨损页，可再读一次比对，或用 ECC 关读取原始数据。
- 大部分页无法纠正：通常说明数据由主控用自己的 ECC（如 BCH）写入、片内 ECC 被关闭。这类芯片必须用 ECC 关读取。

ECC 状态解码：

| 厂商（JEDEC 厂商 ID） | 状态位 | 无法纠正 |
| :--- | :--- | :--- |
| Winbond（EF） | SR[5:4] | 10、11 |
| Micron（2C） | SR[6:4] | 010 |
| 其他（GigaDevice、Macronix、Kioxia、XTX、Foresee 等） | SR[5:4] | 10 |

## 写入规则

- “主数据 + OOB”写入要求 ECC 关，避免芯片改写镜像里的 OOB。
- “仅主数据 + ECC 关”写入前会确认：OOB 中不会生成有效 ECC，之后用片内 ECC 读取会大量报错，只适用于使用主控 ECC 的设备。在自动流程中，这个确认在擦除之前。
- 写入和校验要求缓冲区长度与所选布局完全一致；未完成的读取不能直接写入。
- 跳过坏块写入时，主数据 + OOB 保留物理块位置；仅主数据沿用上游的紧凑策略。
- 擦除按芯片实际的每块页数计算地址。

## 示例：W25N01GW

JEDEC ID `EF BA 21`，每页 2048 字节主数据 + 64 字节 OOB，每块 64 页，共 1024 块：仅主数据 134,217,728 字节（128 MiB），主数据 + OOB 138,412,032 字节（132 MiB）。

W25N01GW 是 1.8 V 芯片，需要正确的 **1.8 V 供电和信号电平转换**；软件电压选项不能替代硬件。保留独立备份，先比较多次读取的结果。

本程序不生成主控端 BCH/QPIC ECC，也不做 OOB 重排或镜像修复。Windows 构建和驱动见 [WINDOWS_CH347.md](WINDOWS_CH347.md)，测试见 [tests/README.md](../tests/README.md)。
