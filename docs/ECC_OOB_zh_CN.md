# SPI NAND：主数据、OOB 与片内 ECC

Windows 增强版把转储布局和片内 ECC 分开选择，沿用 IMSProg 的读取、校验、写入、擦除及组合任务流程。

## 两个独立选项

- 布局：仅主数据，或主数据 + OOB。
- 片内 ECC：开（纠错读取），或关（原始读取）。

这些控件只在 SPI NAND 模式显示。改变 ECC 选项本身不访问芯片，也不修改电脑缓冲区。读取和校验支持全部四种组合，并在每次操作前应用相同的 ECC 设置、回读完整 B0 寄存器。

“主数据 + OOB、ECC 开”包含 OOB，但主数据经过片内纠错，不能称为原始转储。“主数据 + OOB、ECC 关”读取原始字节；关闭 ECC 不会修复错误。

## W25N01GW

按 JEDEC ID `EF BA 21` 识别，使用 2048 字节主数据 + 64 字节 OOB、每块 64 页、1024 块：

- 仅主数据：134,217,728 字节（128 MiB）。
- 主数据 + OOB：138,412,032 字节（132 MiB）。
- 文件内每页主数据后紧跟该页 OOB，再接下一页。

此型号操作前只调整 B0 的 ECC-E（bit 4）及 BUF（bit 3，设为 1），保留其余位并检查完整回读。ID、几何参数、回读不符或通信失败会停止操作；检测到 OTP 模式时不执行主存储区操作。

ECC 开启时，`0x13` 将页载入内部缓存并执行片内纠错，随后 `0x03` 读出缓存。程序报告纠错状态，遇到不可纠正页停止。其他型号沿用原项目的 B0 ECC 约定，不套用 W25N01GW 专用状态解码。

## 数据格式检查

- 写入“主数据 + OOB”要求 ECC 关，避免芯片重写镜像提供的 ECC/OOB 字节。
- 写入和校验要求缓冲区长度与所选布局完全一致。载入文件保留实际长度，不补入旧缓冲区尾部。
- 未完成的 NAND 读取不能直接用于写入；需要重新完整读取或明确载入完整镜像。
- 改变布局会清空缓冲区，有数据时提示确认。只改变 ECC 不会清空。
- 跳过坏块写入时，主数据 + OOB 保留物理块位置；仅主数据沿用上游逻辑紧凑策略。容量不足会报错。
- 擦除仍为整片范围；Load Part 只编辑缓冲区，不限制擦写区域。组合任务遇到错误或取消即停止。
- 现有擦除寻址要求每块 64 页，因此拒绝其他几何组合。

## 使用与验证范围

W25N01GW 需要正确的 **1.8 V 供电和信号电平转换**；软件电压选项不能替代硬件。保留独立备份，并先比较重复读取的结果。

本增强版没有主机端 BCH/QPIC ECC 生成、OOB 重排或镜像修复功能。代码和硬件替身测试不能证明真实 Windows 驱动、编程器、接线或芯片行为；尚未完成实机验收。
