Windows x64 便携版。解压整个 ZIP 后运行 `IMSProg.exe`（未签名，SmartScreen 可能提示）。

## 新功能

- **校验读取（读两次比对）**：工具栏/编程器菜单，快捷键 Ctrl+Shift+R。整片读两遍逐块比对；不一致的块自动降低时钟重读，最低时钟下仍不一致的块再读 7 遍按位多数表决，并报告不稳定的位数。只发送读命令。
- **自动测速**（CH347T/F，编程器菜单里的“自动测速（按芯片实测）”）：对当前芯片和接线实测能稳定读回的最高 SPI 时钟，每个芯片测一次。只发送读命令。
- **速度与剩余时间**：读取、写入、校验、查空时状态栏显示实时速率和预计剩余时间，结束后显示平均速率。
- 芯片库新增 ESMT F50D1G41LB (1.8V)。

## SPI NAND 提速

- Windows 下的短延时不再占用整个系统时钟节拍（原来每次 1 ms 等待实际约 15.6 ms）。
- 状态轮询改为一次 USB 往返（CH347 全双工）；命令与数据合并为一次写；全 FF 的页不再编程。
- 使用沁恒驱动时不再在每次 USB 传输前重复设置超时（每次传输少一次驱动调用，CH341/CH347 均适用）。
- 长时间的块操作期间界面保持响应，“停止”即时生效。

## 修复

- 校验：发现不一致时先降低时钟重读（CH341A/B 时钟固定，改为原速重读最多两次），确认是真实的写入错误才报告，不再把偶发的读错误报成写入失败。
- 校验/查空：跳过标记为坏块的块并列出（与擦除、写入的处理一致）。
- 校验：“仅主数据 + 写入跳过坏块”时，坏块之后的比对位置与写入一致（此前会错位并误报写入错误）。
- 校验：“主数据 + OOB”镜像自身在坏块标记位置带有非 FF 数据时（主控 ECC 布局），该块正常比对，不再当作坏块跳过。
- 未选择芯片时，校验和查空不再提示“操作成功”。
- “保存部分”“导出 Intel HEX”取消后不再生成名为 `.bin` / `.hex` 的文件；“打开”取消后保留上次的目录。
- Intel HEX 导入、“保存部分”的地址越界检查；缓冲区在编辑器中被缩短后，写入/校验会提示而不是越界读取。
- AT45DB 4224K 无 JEDEC ID 时按状态寄存器识别容量。
- 自动测速：测量期间暂停后台的编程器连接检测。此前它会在测量中途关闭连接，导致每档时钟都判为失败，结果总是 1.875 MHz。
- 自动测速：Winbond 芯片处于连续读模式（BUF=0）时先切到缓冲模式再测。

## 验证

- 硬件无关回归：NAND 模拟 SPI、CH341/CH347 后端（含 ASan/UBSan）、Qt 主窗口集成测试，Windows 启动冒烟测试。
- 实机：SPI NAND 的读取/擦除/写入/校验流程经作者实机使用；本版最后加入的修复项（见“修复”后六条）只经过硬件无关回归。

## 注意

- 1.8 V 芯片需要 1.8 V 供电**和信号电平转换**，软件电压选项不能替代硬件。
- 写入 SPI NAND 前请先用“校验读取”做备份。
- `driver\` 中的驱动和 DLL 版权归沁恒（WCH）所有，按其“随产品发行到最终用户”的用途随附；程序运行时加载，不与其链接。源码见 `SOURCE\`。
